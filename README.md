# Simple Asteroid 2d game. 

A small pixel-art space shooter prototype built with JavaScript and PixiJS.

## Tech Stack

- JavaScript
- PixiJS
- Vite
- HTML/CSS

## Current Features

- Player movement
- Mouse aiming
- Shooting
- Enemy aliens
- Bullet collision
- Score system
- Enemy spawning
- Game over and restart
